# ЛР 1 Дерево поиска и множество

Шаблонное AVL-дерево на std::unique_ptr и множество на его основе. Выбранные функции составляют 25 рейтинговых баллов: 17 за дерево и 8 за множество. Таблица пунктов и все правила находятся в [TASK.md](TASK.md).

## Сборка и запуск

Нужны компилятор с C++17 и make. Основная программа и тесты используют только стандартную библиотеку.

Из папки BinarySearchTree:

```sh
make
make run
make run_tests
```

Отдельная проверка ошибок памяти и неопределённого поведения, если компилятор поддерживает соответствующие средства:

```sh
make check
```

Команда make clean удаляет только собранные программы, объектные файлы и отладочную папку проверки; исходники и результаты остаются. Makefile содержит явные зависимости и команды по стилю SequenceADT_CPP. Очистка рассчитана на macOS/Linux.

## Как пользоваться меню

Сначала выбрать тип: int, double, string или Student. Затем выбрать дерево или множество. Контейнеры начинают пустыми. При возвращении к выбору типа контейнеры текущего сеанса освобождаются.

Для дерева доступны ввод, генерация, вставка, поиск, удаление, Map, Where, Reduce, поддерево, копия, запись и чтение. Map, Where, Clone и GetSubtree сохраняют отдельный последний результат, который можно проверить на вхождение. Для собственного кандидата есть команда чтения строки в результат. Пустой кандидат считается входящим поддеревом.

Команда показа печатает первые 25 элементов и вид дерева сбоку: правая ветка выше корня, левая ниже. Число элементов и высота показываются отдельно. Строка сохранения по явной команде выводится полностью.

В режиме множества есть A и B. Можно вводить или генерировать оба, изменять A, строить объединение/пересечение/разность и проверять включение и равенство. Создающие операции сохраняют отдельный результат.

Автоматическая генерация принимает число уникальных элементов, диапазон ключей и seed. Для студентов диапазон ID должен быть положительным. Повторный seed и параметры воспроизводят тот же набор. Генератор меню использует арифметическую перестановку ключей без массива всего диапазона; генератор измерений использует std::shuffle.

Студент вводится одной строкой:

```text
12 "Иван" "Иванович" "Петров" "2005-01-01"
```

Пустое отчество: "". Для поиска, удаления и корня поддерева нужен только ID. Студенты с одинаковым ID считаются одним ключом; повтор сохраняет первого студента.

Демонстрационные функции:

| Тип | Map | Where | Reduce |
|---|---|---|---|
| int | Изменить знак | Чётные | Сумма со стартом 0 |
| double | Изменить знак | Положительные | Сумма со стартом 0 |
| string | Добавить ! | Непустые | Соединить через разделитель |
| Student | Добавить + к фамилии | Чётные ID | Найти минимальный ID |

Для пустого Student-Reduce возвращается стартовая запись с ID=INT_MAX. Основные классы позволяют передавать собственные функции; эти четыре набора относятся только к демонстрационному меню.

## С чего читать код

1. Set.hpp — небольшой абстрактный интерфейс.
2. TreeSet.hpp — как множество использует дерево и выполняет операции над содержимым.
3. BinarySearchTree.hpp — поиск, вставка, удаление и AVL-повороты.
4. Tree.hpp — общие обходы, копирование, Map/Where/Reduce, поддеревья и формат строк.
5. TreeTests.cpp и SetTests.cpp — небольшие примеры использования и ожидаемые результаты.
6. main.cpp — консольное меню и демонстрационные функции.

Tree и Set имеют виртуальные операции и деструкторы, реализации вызываются через базовые ссылки/указатели. T задаёт тип элементов; одному дереву не требуется хранить разные типы вперемешку.

## Пример использования

```cpp
BinarySearchTree<int> object;
Tree<int>& tree = object;
tree.Insert(5);
tree.Insert(3);
tree.Insert(7);

std::unique_ptr<Tree<int>> branch = tree.GetSubtree(3);
bool included = tree.ContainsSubtree(*branch);
std::string text = tree.ToString(ValueToString<int>);
```

Нужные заголовки: BinarySearchTree.hpp для дерева и TreeSet.hpp для множества. Свои типы получают явный компаратор и функции преобразования строк; пример Student и тестовый Record не имеют operator<. Узлу не нужен конструктор T без аргументов.

Ключи эквивалентны, когда компаратор не считает ни один меньше другого. Двухместные операции требуют той же переданной функции сравнения. Копии и результаты имеют независимые узлы. Map и Where могут изменить форму, копирование и GetSubtree сохраняют форму.

## Сохранение дерева

```text
("5" ("3" # #) ("7" # #))
```

Обход КЛП, # — пустая ветвь. Кавычки и обратные косые черты внутри значения экранируются. Для восстановления:

```cpp
tree.ReadFromString(text, ValueFromString<int>);
```

Чтение проверяет формат, глобальный порядок и AVL-баланс, затем заменяет дерево. При ошибке прежний объект сохраняется. Подробные правила и ограничения приведены в ТЗ.

## Что проверяют тесты

12 групп: базовые операции и полиморфизм; четыре AVL-поворота и удаления; независимые копии; Map/Where/Reduce; поддеревья; формат и повреждённые строки; разные типы; время жизни и исключения; базовое множество; операции множеств; преобразования и типы множества; ошибки множества.

Смешанный тест сравнивает 3000 операций со стандартным множеством. Независимая проверка пересчитывает высоты, а проверка отсортированных значений сравнивает содержимое с эталоном. Отдельный тип считает живые объекты и имитирует ошибки копирования и callback, проверяя освобождение временных результатов.

В арифметическом примере задания Reduce правильный ответ 144, а не указанный там 132: 14 → 46 → 144. Тест следует формуле f(x,y)=2*x+3*y и порядку func(element, result).

## Измерения и графики

```sh
make run_benchmark
```

Эта цель выполняет по три повтора до миллиона элементов. Она перезаписывает results/timings.csv. Подробный запуск:

```sh
make benchmark
./benchmark 100000000 results/large_sorted.csv 1 sorted 0
./benchmark 100000000 results/large_random.csv 1 random 0
```

Аргументы: максимальный N, путь CSV, повторы, both/sorted/random, предел подробных операций, seed. По умолчанию: 1000000, results/timings.csv, 3, both, 1000000, 2026. Предел 0 отключает подробные операции. Большие запуски выполняются последовательно и требуют нескольких гигабайт памяти.

В CSV: n — реальное количество узлов перед операцией; order — порядок исходных ключей; operation — алгоритм; calls — число вызовов в измеряемой серии; repeat — номер повтора; time_ms — полное время серии; checksum — результат для проверки выполненной работы. Для операций над множествами n — размер каждого исходного множества.

Построение измеряется для N вставок, поиск и удаление — для min(N,10000) вызовов. Сложные операции вызываются один раз на контейнере размера N. Reduce в измерениях выполняет XOR, чтобы сумма больших int не переполнялась. Вхождение поддерева проверяется на копии всего дерева. Множества строятся отдельно по порядку: A=0..N-1, B=N/2..N/2+N-1.

Генерация входа, проверки и уничтожение результатов не включены в время алгоритма. Дерево проверяется после удаления. Подробные операции по умолчанию измеряются до 10^6, базовые допускают 10^8; это разные диапазоны измерений.

Для построения графиков отдельно требуется Python и matplotlib:

```sh
python3 -m pip install matplotlib
python3 plot_results.py
```

Либо make plots. Сценарий читает имеющиеся CSV из results и создаёт summary.csv и три PNG-графика. Для своих файлов: python3 plot_results.py путь1.csv путь2.csv --output results. Summary использует медиану всех доступных повторов каждой серии. Для базовых точек до миллиона стандартный набор сохранённых файлов может содержать дополнительные повторы из больших запусков; число samples указано явно.

Фактические результаты и условия текущего запуска приведены в [results/REPORT.md](results/REPORT.md). Время на другом компьютере будет отличаться.

## Сложность и материал для защиты

AVL поддерживает разницу высот левой и правой ветвей не больше 1. Поворот меняет связи локально, сохраняя порядок ключей. При удалении узла с двумя потомками переносится следующий узел из правой ветки.

При постоянной стоимости сравнения поиск, вставка и удаление — O(log N); обход, Reduce и копирование — O(N); Map и Where через повторную вставку — O(N log N). Извлечение и проверка поддерева размером M — O(log N + M). Сохранение и чтение — O(L + N), L — длина строки.

Простое объединение копирует левое множество и вставляет элементы правого. Пересечение, разность и включение используют поиск. Временный GetItems выделяет массив значений; основное хранение остаётся деревом. Внутренние обходы дерева не создают массив и не выполняют повторные поиски каждого узла.
