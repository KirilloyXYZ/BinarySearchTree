# Лабораторная работа 1

Шаблонное AVL-дерево с отдельными ключами и значениями. Реализованы вставка, поиск,
удаление, шесть обходов, Map, Where, Reduce, перечислитель, операции с поддеревьями
и перегрузка операторов. На дереве построено множество Set с операциями над наборами.
Консольное приложение
работает с целочисленными ключами и значениями; библиотека поддерживает и другие типы.

## Запуск

Нужен компилятор C++17. На macOS команда g++ может запускать Apple Clang.

```sh
make run
make test
make sanitize
```

В меню доступны ручная вставка, поиск, удаление, очистка, генерация, вывод веток,
шесть обходов, Map (смена знака или квадрат), Where (чётные или положительные)
и Reduce (сумма с начальным значением). Пункт 11 извлекает копию поддерева по ключу,
пункт 12 проверяет вхождение поддерева, пары которого вводятся вручную.
Пункт 13 открывает работу с множествами A и B.
Каждое число вводится на отдельной строке.
При переполнении арифметической операции выводится ошибка. Конец ввода завершает приложение.

Для веток используется UTF-8. К — корень, Л — левый потомок, П — правый.
По умолчанию выводятся не более 100 узлов и 8 уровней. Пункт «Показать дерево»
позволяет изменить ограничения. Обход показывает первые 100 записей.
Map и Where показывают отдельный результат и сохраняют исходное дерево.

В BinarySearchTree оператор [] читает значение без вставки, += добавляет пару,
сохраняя прежнее значение при повторном ключе. Например:

```cpp
BinarySearchTree<int, int> tree;
(tree += {2, 20}) += {1, 10};
std::cout << tree[1] << '\n';
auto subtree = tree.GetSubtree(1);
std::cout << tree.ContainsSubtree(*subtree) << '\n';
```

GetSubtree сохраняет форму дерева и возвращает независимую копию его узлов.
Отсутствующий ключ в [] или GetSubtree вызывает out_of_range. ContainsSubtree
сравнивает структуру, значения и ключи; эквивалентность ключей задаётся компаратором
исходного дерева. Одного наличия всех элементов недостаточно. Пустое поддерево входит
в любое дерево. Для значений без == передаётся функция равенства вторым аргументом
ContainsSubtree. Вводимый в меню образец строится как AVL-дерево, и программа показывает
его фактическую структуру перед проверкой.

Генерация заменяет текущее дерево только после успешного построения нового.
Ключи различны и равномерно распределены по заданному целочисленному диапазону;
режим определяет порядок их вставки. Случайный режим перемешивает этот набор,
а не выбирает независимые случайные ключи с повторениями. Значения генерируются
случайно в том же диапазоне. Одинаковые параметры и seed воспроизводят данные
при той же реализации стандартной библиотеки.

## Множества

`Set<T>` хранит элементы как ключи `BinarySearchTree<bool, T>`. Вставка дубликата
и удаление отсутствующего элемента возвращают false. Доступны Insert, Remove,
Contains, GetCount, IsEmpty, Clear и Print. Вывод по умолчанию ограничен 100 элементами.

Union, Intersection и Difference возвращают независимые результаты через
`std::unique_ptr<Set<T>>`. IsSubsetOf проверяет включение текущего множества в другое,
Equals — равенство элементов независимо от формы деревьев и порядка вставки.

```cpp
Set<int> first;
Set<int> second;
first.Insert(1);
first.Insert(2);
second.Insert(2);
second.Insert(3);
auto result = first.Union(second);
result->Print(std::cout); // {1, 2, 3}
```

Конструктор принимает функцию сравнения, по умолчанию — `<`. Она определяет
эквивалентность элементов: они одинаковы для множества, если ни один не меньше другого.
Оператор == элементам не нужен. Операции между множествами требуют одного и того же
указателя на функцию сравнения, иначе вызывают invalid_argument, включая пустые множества.
Результат сохраняет компаратор; при эквивалентных представителях Union сохраняет элемент
из первого множества, Intersection и Difference также используют его элементы.
Print требует возможности вывести T в поток; остальные операции этого не требуют.

В пункте 13 можно добавлять элементы в A или B, искать, удалять и очищать их, показывать
оба набора, получать объединение, пересечение и разность в обоих направлениях,
проверять включение в обоих направлениях и равенство. Ввод дополняет выбранный набор,
повторы подсчитываются. A и B сохраняются при выходе из подменю до завершения программы.
Операции показывают исходные наборы и результат, не заменяя A и B.

## Замеры и графики

```sh
make benchmark
make setup
make graphs
```

Бенчмарк собирается с `-O2`. По умолчанию проверяет размеры от 10 000 до 1 000 000,
три порядка вставки и три повтора. CSV сохраняет каждый повтор отдельно.
`make setup` один раз создаёт локальное окружение Python и устанавливает Matplotlib.
Графики сохраняются рядом с CSV в SVG и PNG. Можно задать другой Python:
`make graphs PYTHON=python3`.

Параметры бенчмарка: максимальное число узлов, число повторов, seed, путь к CSV.

```sh
make lab1_bench
./lab1_bench 10000000 3 17 results/benchmark.csv
./lab1_bench 100000000 3 17 results/large.csv
.venv/bin/python plot_benchmarks.py results/large.csv
```

Допустимый максимум — 100 000 000 узлов, повторы — от 1 до 15.
Программа проходит размеры 10 000, 30 000, 100 000, 300 000 и далее по той же схеме,
добавляя указанный максимум, если его нет в списке. Большой запуск требует
соответствующего времени и памяти; в результатах следует указывать фактические размеры.

Для каждого размера используются одинаковые ключи от 0 до n−1:

- построение: n вставок в выбранном порядке;
- поиск: n успешных и n неуспешных запросов в одинаковой для всех режимов последовательности;
- обход: полный ЛКП с подсчётом посещений и контрольной суммы значений;
- удаление: n удалений в порядке вставки.

Генерация, проверки результата, запись CSV и печать находятся вне замеряемых участков.
Обход выполняется до удаления. Для каждого повтора создаётся новое дерево;
seed увеличивается на номер повтора, начиная с нуля. Проверяются количества найденных,
посещённых и удалённых узлов и контрольная сумма. На графиках показана медиана
времени всего пакета операций, обе оси логарифмические.

в [results/README.md](results/README.md). `make clean` удаляет только сборочные файлы.
