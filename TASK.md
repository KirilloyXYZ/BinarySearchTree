# Техническое задание ЛР 1

## Назначение

Реализовать на C++17 универсальное бинарное дерево поиска с AVL-балансировкой и множество на его основе. Программа предназначена для изучения алгоритмов, проверки операций через консольное меню и измерения времени выполнения.

Основание: ЛР-1.docx, предоставленный пользователем. Стиль оформления выбран по репозиторию [SequenceADT_CPP](https://github.com/KirilloyXYZ/SequenceADT_CPP).

## Требования к данным

Один контейнер хранит один тип T. Один шаблон работает с разными типами; смешивание разных типов в одном экземпляре не предусмотрено.

T должен поддерживать копирующее конструирование, а для Reduce также присваивание возвращаемого функцией результата. Деструктор элемента не должен выбрасывать исключения. Функция сравнения имеет вид bool(const T&, const T&) и задаёт строгое устойчивое упорядочение. Эквивалентность ключей означает, что ни один из них не меньше другого. Сами элементы нельзя изменять через выданные константные ссылки.

Сравнение передаётся явно или используется CompareValues<T> для типа с operator<. Пользовательскому типу с собственной функцией сравнения operator< и operator== не нужны. Конструктор без аргументов нужен только вспомогательному ValueFromString<T>, а не самому контейнеру; явный читатель может создать T любым способом. Для восстановления согласованная пара функций записи и чтения должна сохранять исходное значение.

Преобразование задаётся T(const T&), фильтр — bool(const T&), свёртка — T(const T&, const T&). Функции не должны менять исходные элементы через const_cast. Сохранение принимает std::string(const T&), чтение — T(const std::string&).

Демонстрационные типы: int, конечный double, std::string, Student. Комплексные числа и функции могут быть добавлены с явно заданными порядком и преобразованием строк; обязательность всех перечисленных в исходнике типов не уточнена.

Student имеет положительный ID, имя, отчество, фамилию и дату рождения YYYY-MM-DD. Имя и фамилия непустые, отчество может быть пустым. Дата проверяется с учётом високосного года. ID определяет равенство ключей; повтор с тем же ID не заменяет ранее сохранённые поля.

## Архитектура и память

Tree<T> — абстрактная основа с общими алгоритмами, BinarySearchTree<T> — реализация поиска и AVL, Set<T> — интерфейс множества, TreeSet<T> — реализация через принадлежащее ему дерево. Публичные операции доступны виртуально, деструкторы базовых классов виртуальны. Вспомогательные функции и узлы не требуют отдельного полиморфизма.

Узел содержит значение, unique_ptr на левую и правую ветки и высоту. Корень принадлежит дереву, дерево принадлежит множеству. Совместного владения нет. Повороты и удаление переподключают указатели. Копирование и присваивание создают независимые узлы, сохраняя форму.

Создающие операции возвращают unique_ptr на базовый класс. GetItems возвращает копии значений и принимает необязательный лимит: меню использует 25. GetRoot возвращает константную ссылку, которая перестаёт быть действительной после удаления соответствующего узла, очистки, чтения нового дерева или уничтожения контейнера.

## Семантика операций

Insert возвращает true при добавлении и false для эквивалентного ключа. Contains возвращает результат поиска. Remove возвращает true при удалении и false при отсутствии. Отсутствие ключа в этих операциях — обычный результат.

Map и Where создают новый сбалансированный контейнер. Исходник не меняется; форма результата может измениться. Эквивалентные результаты Map сохраняются один раз. Порядок применения функций — ЛКП.

Reduce выполняет ЛКП и вычисляет result = func(element, result), начиная со startValue. Для пустого контейнера возвращает startValue. Порядок важен для некоммутативной функции.

GetSubtree копирует заданный корень и всех его потомков, сохраняя структуру. Отсутствующий корень вызывает out_of_range. ContainsSubtree проверяет структуру, пустые ветви и эквивалентность ключей. Пустое поддерево входит в любое дерево. Компараторы обоих деревьев должны быть одной переданной функцией.

Union, Intersection и Difference возвращают новое множество. Difference — элементы левого множества, которых нет в правом. IsSubsetOf проверяет включение текущего множества в аргумент, Equals — равенство по ключам независимо от формы. Для всех двухместных операций требуется одинаковая функция сравнения: при различии указателей на функции выбрасывается invalid_argument.

## Формат дерева

Фиксированный обход — КЛП. Грамматика:

```text
tree = # | ("value" tree tree)
```

Пример:

```text
("5" ("3" # #) ("7" # #))
```

Пробелы между структурными символами допустимы. Значение всегда заключено в кавычки; кавычки и обратные косые черты экранируются по правилам std::quoted. # внутри кавычек — значение, вне кавычек — пустая ветвь.

Читатель сначала восстанавливает временные узлы, затем проверяет весь ввод, глобальный порядок, уникальность и AVL-баланс. Высоты вычисляются заново. Максимальная глубина разбора — 64: этого достаточно для AVL с размером, ограниченным INT_MAX. Неверная строка не заменяет прежнее дерево. Структура корректного round-trip сохраняется.

Студент записывается как ID и четыре строки в кавычках: имя, отчество, фамилия, дата. Эти данные дополнительно экранируются, когда становятся строковым значением узла.

## Ошибки и ограничения

Нулевая обязательная функция, отрицательный count, нулевой массив с положительным count, отрицательный лимит, повреждённая строка и несовместимые компараторы вызывают исключения. Пустой массив с count=0 допустим. При ошибке создания временного результата его память освобождается.

GetRoot пустого дерева вызывает out_of_range. Размер ограничен INT_MAX. Print показывает дерево сбоку и принимает глубину от 1 до 10; ограничение относится только к отображению, а не к самому дереву.

Консольное меню корректно обрабатывает неверные числа, неизвестные команды и конец ввода. Автоматическая генерация принимает число уникальных ключей, минимальный и максимальный ключ и seed. Диапазон должен вмещать запрошенное число. Сопростой шаг обеспечивает уникальность без массива всего диапазона; это арифметическая перестановка, а не равномерное перемешивание всех перестановок.

Для демонстрационного int изменение знака INT_MIN и переполнение суммы вызывают overflow_error. Для double при вводе не принимаются NaN и бесконечности. Поддержка иных областей чисел определяется пользовательскими функциями.

## Приёмка и измерения

Проверяются основные случаи операций, пустые контейнеры, ошибки, все четыре вида AVL-поворотов, повторные удаления, копии, round-trip, разные типы и вызовы через базовые интерфейсы. Смешанные операции сравниваются со std::set только в тесте-эталоне. В тестах должен быть активен assert; NDEBUG не используется.

Измерения выполняются отдельной оптимизированной программой. Данные — уникальные ключи по порядку и полностью перемешанный массив через std::shuffle с фиксированным seed. Фактические размеры и результаты фиксируются в CSV. Генерация, вывод, проверка инвариантов и освобождение результата не входят во время операции. Время измеряется steady_clock.

Базовые операции предусмотрены до 10^8 узлов. Сложные создающие операции и операции множеств измеряются отдельно до заданного detailedLimit, по умолчанию 10^6. Графики показывают только реальные точки. Поиск и удаление измеряются сериями до 10 000 вызовов; графики показывают время одного вызова. База и сложные операции с разным верхним объёмом не объявляются проверенными в одинаковом диапазоне.

## Особенности исходного задания

Умные указатели, конкретный AVL-алгоритм, формат строк, отсутствие дубликатов в базовом дереве и точная семантика отдельных операций — согласованные решения реализации, не дословные обязательные указания.

В примере Reduce допущена арифметическая ошибка: для f(x,y)=2*x+3*y, [1,2,3], c=4 шаги равны 14, 46, 144, хотя в документе указан ответ 132. Реализация выполняет формулу и проверяет 144.

В критериях качества кода подпункты дают 7, но максимум строки — 6. Буквальные условия зачёта: код не меньше 3, полнота и ТЗ не меньше 3, теория больше 0, сумма пунктов 1–5 без оригинальности не меньше 17. Правила крайних объёмов измерений и обязательность всех типов остаются вопросами к преподавателю.
